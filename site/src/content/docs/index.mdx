## 每一节的结构

33 节都从“现场问题”开始、以“参考资料”结束，中间是同一套顺序：

| 每一节里的块 | 你会看到什么 |
| --- | --- |
| 现场问题 | 一段真实场景，末尾是一句被引用的提问。每节开头的固定标题 |
| 术语名称（中英对照） | 本节的核心词，第一次出现就给英文原词 |
| 一句话听懂 | 紧跟术语的加粗结论句，用大白话说清它是什么 |
| 上下游影响 | 这一层怎么影响别的层，又被谁约束 |
| G1 落地 | 这些说法在宇树 G1 上的具体落点：模型、关节、消息或仿真现象 |
| 参考资料 | 编号来源，可以点开逐个核对。每节末尾的固定标题 |

其中只有“现场问题”和“参考资料”是标题，其余几块写在正文里——所以查词请搜术语名，核对数字请翻到节末。

用法：赶时间就只读现场问题、术语定义和紧跟其后的第一条“一句话听懂”；要查某个词就直接搜它；要核对数字就顺着 G1 参数和参考资料往下挖。

## 贯穿案例：Unitree G1

全书用宇树 G1 人形机器人作为唯一贯穿案例。无手、锁腰、带手三个模型变体按场景切换，所有模型文件、SDK 消息字段和关节参数都来自宇树官方开源仓库，可以逐个核对来源。
