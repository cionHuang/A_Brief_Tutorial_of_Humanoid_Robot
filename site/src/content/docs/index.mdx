## 这本书解决什么问题

机器人项目里，机械、嵌入式、算法、软件说的是四套语言。这本书把它们翻译成一套，每个术语都在一台真实的 G1 人形机器人上找到对应。

## 三种读法

## 每一节的固定套路

```text
现场问题 → 黑话名称（中英对照）→ 人话解释 → 上下游影响 → G1 落地 → 参考资料
```

知道这个套路后，你可以直接跳到自己需要的部分：赶时间就只读前两块，要深入就顺着 G1 参数和参考资料往下挖。

## 贯穿案例：Unitree G1

全书用宇树 G1 人形机器人作为唯一贯穿案例。无手、锁腰、带手三个模型变体按场景切换，所有模型文件、SDK 消息字段和关节参数都来自宇树官方开源仓库，可以逐个核对来源。
