# 5.7 从 VLA/WAM 到 G1 控制接口

## 先看一个现场问题

研究团队把 VLA 输出直接接到 G1 的关节位置接口：模型第一次输出末端目标，IK 求解成功；第二次输出跳到了另一个解分支，手臂瞬间抖动；第三次模型因为画面遮挡给出了桌子后方的位置，控制器仍然照做，手直接撞上桌沿。把同样的输出先经过限幅、工作空间检查、碰撞检查和轨迹衔接，动作变慢了，但不再出现瞬时跳变。

现场通常会这样问：

> “模型输出的 action 到底对应什么物理量？它应该直接给电机，还是先变成末端目标？模型更新慢、底层控制快，中间谁负责衔接？”

VLA 和 WAM 输出的都不是天然安全的电机命令。它们更适合被理解为“动作意图”或“短期动作计划”：必须经过语义解码、坐标变换、限幅、轨迹衔接和安全过滤，才能进入 G1 的控制栈。

## 高级模型到低层控制的链路

一条合理的链路是：

```text
相机/语言/机器人状态
  → VLA 或 WAM
  → 动作解码（Action Decoding）
  → 坐标系与时间戳检查
  → 限幅、碰撞和稳定性检查
  → IK / 轨迹规划 / WBC
  → G1 关节位置、速度或力矩接口
```

这条链路的核心原则是分层负责：高级模型决定意图，规划和控制层负责把意图变成满足物理约束的运动，底层接口只接收经过检查的目标。

## 接口契约

接入 G1 前，至少要写清以下字段。没有这些契约，模型“输出了一个数组”并不能证明它可以控制机器人。

| 字段 | 必须回答的问题 |
| --- | --- |
| 动作语义 | 是末端位姿、末端增量、关节角、速度、力矩，还是技能调用 |
| 参考坐标系 | 末端目标在世界系、骨盆系还是相机系 |
| 时间基准 | 动作对应哪个测量时刻，动作块从何时开始执行 |
| 更新频率 | 模型多久输出一次，动作块覆盖多长时间 |
| 动作维度 | 是否包含腰部、双臂、手指和移动基座 |
| 限幅规则 | 位置、速度、加速度、力矩和变化率上限 |
| 失败语义 | 超时、无新输出、IK 无解或接触异常时如何降级 |

动作块的执行尤其需要时间基准。模型在 `t0` 时刻根据观测生成未来 500 ms 的动作，控制器就必须知道这段动作从哪个时间点开始、每个动作步间隔多少、中途收到新观测后是否允许提前截断。

## 安全过滤层

模型输出进入规划或控制之前，至少经过四类检查：

1. **数值检查**：拒绝 `NaN`、无穷大、超出动作维度和异常大的增量；
2. **运动学检查**：关节限位、IK 解存在性、解分支连续性和工作空间边界；
3. **动力学与平衡检查**：质心、ZMP、接触状态、速度和力矩约束；
4. **碰撞检查**：自碰撞、环境碰撞和必要的安全距离。

这些检查不改变模型的智能程度，它们决定的是“模型犯错时系统是否会立刻变成危险动作”。学习模型越复杂、越难解释，下游约束就越应该确定、可测试、可记录。

## 以 G1 为例

对带手 G1，VLA/WAM 可以输出“左手末端前移 5 cm，同时三根手指闭合”的动作意图。合理路径是：

1. 感知模块给出杯子位姿，带坐标系和时间戳；
2. VLA/WAM 输出双臂和手指动作块；
3. 动作解码器把模型内部动作单位转换成米、弧度和关节名称；
4. 安全层检查桌面碰撞、手指闭合速度、肘部自碰撞和 ZMP 裕量；
5. IK 或规划器生成平滑轨迹；
6. WBC 分配手臂、腰部和支撑腿任务；
7. 关节级接口按 `kp`、`kd`、目标位置和力矩前馈执行。

如果模型输出直接跳过第 4–6 步，问题不会立刻表现为模型不聪明，而会表现为抖动、撞桌、失去平衡或关节命令突变。把这些边界写清楚，VLA/WAM 才能作为“大脑”接入系统，而不是绕过“小脑”和底层保护。
