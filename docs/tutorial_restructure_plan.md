## 1. 新增一个锚点：1.4「从一句话到电机」

在第一章末尾新增一节（不动 1.1–1.3 的编号），承担四件事：

1. 给出**整机总图**：纵向功能链 4 层（任务与智能 / 行为与技能 / 运动与规划 / 实时控制）+ 驱动与嵌入式 + 机械执行；横向基础设施 6 类（ROS 与中间件、计算平台、安全、数据与日志、仿真与工具、配置模型与标定）。
2. **频率金字塔**：0.1–1 Hz（任务）→ 1–10 Hz（技能）→ 10–100 Hz（规划）→ 200 Hz–1 kHz（WBC/关节）→ 1–20 kHz（电流环）；一句话结论："越靠近物理世界，闭环越快；VLA 推理时低层不会停。"
3. **算法跑在哪里**：GPU（VLA/视觉）→ CPU（任务/规划）→ 实时 CPU（估计/WBC）→ MCU（关节/电流环）→ 总线 → 电机。
4. **两个闭环**：在线运行闭环 vs 离线开发闭环（明确"运行时训练吗""reward 还在吗""Isaac Lab 部署时跑吗""遥操作数据何时用"）。

同时把这张图变成**全书的回归锚点**：每一节开头加一句"在整机里的位置"（一句话，不新增段落）。

## 二、传感与状态（反馈链，自下而上）

| 传感器 | 提供什么 | 去哪 | 频率 |
| --- | --- | --- | --- |
| 编码器 | 关节角、角速度 | 驱动器内部的电流/速度/位置环 | 与电流环同周期（1–20 kHz） |
| IMU | 姿态、角速度、加速度 | 状态估计 → 平衡控制 | 200 Hz–1 kHz |
| 相机（RGB/深度） | 图像、点云 | 感知（检测/分割/位姿）→ 世界状态 | 10–30 Hz |
| LiDAR | 点云、地图 | SLAM / 导航 | 10–20 Hz |
| 力/力矩、足底、触觉 | 接触力、滑移、接触状态 | 阻抗/力控、抓取判定、失败检测 | 100 Hz–1 kHz |

感知与状态估计的输出**同时喂给三层**：任务层（世界变了吗）、规划层（障碍/目标）、控制层（自身状态）。

## 三、横向基础设施（每一层都要用，但不属于任何一层）

| 基础设施 | 它做什么 | 书中位置 |
| --- | --- | --- |
| 中间件与软件架构 | 把算法变成进程/节点，用 Topic/Service 连起来（ROS 2 / DDS） | 6.1 |
| 计算平台 | GPU（VLA/视觉）→ CPU（任务/规划）→ 实时 CPU（估计/WBC）→ MCU（关节/电流环） | 3.5 + 新增"算法跑在哪里" |
| 安全 | 硬件保护（急停/过流/过温/超时）+ 运行时安全过滤（限位/碰撞/可行性/命令新鲜度） | 3.6 + §17 |
| 数据与日志 | 记录 → 回放 → 失败挖掘 → 数据集 | 5.5 + §14 |
| 仿真与工具 | MuJoCo / Isaac / Gazebo / RViz / Foxglove | 6.2–6.5 |
| 配置、模型与标定 | URDF/MJCF、参数、固件、版本 | 2.5、6.6 |

> 关键澄清：**ROS 不在"大脑下面"**。它是横向的软件基础设施，大脑、小脑、感知、仿真都在用它。

## 四、两个闭环（不要混）

**在线运行闭环**（机器人身上，每个频率各有一圈）
传感 → 感知/状态估计 → 任务/规划/策略 → 安全过滤 → 控制 → 驱动 → 电机 → 环境 → 传感 → …

**离线开发闭环**（开发机上，不跑在机器人上）
遥操作/仿真/真机日志 → 数据集 → 训练 → 评测 → 导出部署 → 回到机器人 → 继续采集

> 运行时**不训练**：真机上没有 reward、没有优化器；Isaac Lab 只在离线侧出现。遥操作数据只在离线侧被消费。
