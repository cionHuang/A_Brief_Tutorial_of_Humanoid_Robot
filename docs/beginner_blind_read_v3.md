# 零基础盲读验收报告（Phase 5）

对《“听懂”具身智能——以人形机器人为例》做一次“零基础读者模拟”：由三个互相独立的读者代理通读全文，只报卡点，不报好评；报告落地后再由主笔逐条修复并机器校验。

## 一、方法与样本

- 读者设定：会一点编程、听说过 AI，没学过机械/控制/机器人，这些术语第一次见。
- 分工：ch1–2、ch3–4、ch5–6 各一名读者，按 `chapters/00-reading-guides/02-student.md` 的顺序逐节读正文（跳过参考资料）。
- 每节回答五问：① 这个词是干什么的？② 为什么会需要它？③ 它在机器人哪里？④ 它跟谁发生关系？⑤ 我能不能继续往下读？
- 每章最多报 8 条一级卡点，按严重程度排序；另附次级候选清单。全程只读，不改文件。

## 二、主要发现（共性问题）

1. **安全退出点大量错位**（本轮最严重）。11 处“第一次阅读到这里即可”插在正文中段，描述的内容常常在它上面、真正该跳过的在它下面；个别还把后文要用的定义划进“可跳过”（最典型是 4.3 把 $M$、$C$、$g$ 记号表划进跳读区，导致后面正/逆动力学断链）。对零基础读者，它不是安全网，而是一张会漏人的网。
2. **前向引用成体系**：IMU、编码器、总线、状态估计、pitch/roll、雅可比、广义力、接触富集、RANSAC、Sim2Sim、闭链、VLM 等词在解释之前就被当作已知使用，救援句往往是“见 4.2 节”，而读者正卡在这一句上。
3. **同一概念两套说法**：节点是不是独立进程（6.1 同节前后矛盾）、黑色桌面深度空洞归谁管（传感器原理 vs 标定）、VLA 会不会学“动作→后果”（5.6 与 5.7 冲突，会抹掉 WAM 的增量）、MPC 属大脑还是小脑（相邻两张表）、学习控制的层级定位（5.1 与 5.5 不一致）。
4. **密集段落无缓冲**：5.1 强化学习十词连发、6.3 一句八个专有名词、3.1 电源树一段十来个新词、3.2 逆变器四部件、3.4 一句四个缩写。
5. **绝对化措辞残留一处**：5.1“机器人上电后跑的都是推理”与同节“在线（边跑边学）”自相矛盾——正好命中本轮要防的 Online/Offline 错误认知。

## 四、修复后的停靠点（给导读用）

- 4.1：读到「数值之外还要写清什么」那三条约定；只有标“进阶”的推导（万向节锁矩阵推导、指数映射）可跳。
- 4.2：至少读完奇异位形——本节开头第三问的答案在那里。
- 4.3：记号表必读，方程推导可跳。
- 4.4：延迟/零偏/可观测性/接触状态估计属于第二层，但接触状态估计是 4.6 的前置。
- 4.5：全读，自洽。
- 4.6：从「约束不是附属品」继续接得上。
- 3.3：从「标定：内参与外参」起是本节开头问题的答案，建议读完。
- 3.5：需读到「怎样判断控制周期是否可靠」。
