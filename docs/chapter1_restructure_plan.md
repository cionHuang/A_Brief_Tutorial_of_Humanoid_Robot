## 3. 新 1.3 的骨架（唯一架构节）

```
现场问题：红杯子那句话，怎么变成电机转动？
术语：纵向功能链 / 横向基础设施 / 闭环频率
唯一总图：六层 + 两条链（canonical 图 + 一张表）
  └ 表列：层 / 它决定什么 / 输入 → 输出 / 典型频率 / 俗称（大脑·小脑仅此处出现一次，并声明是比喻）
红杯子走一遍：从语言到电机，再到失败恢复
为什么同时跑着好几个钟：频率金字塔（数量级）
算法跑在哪里：GPU / CPU / 实时 CPU / MCU + 总线
旁边还有一组横向基础设施：ROS、安全、日志、配置、仿真
在线运行 vs 离线开发
G1 落地：两个消息名 + 500 Hz + 安装坐标系
参考资料
```

**canonical 图**（新组件 `SystemMap.astro`）：纵向六层 + 左侧频率带 + 右侧上行反馈箭头 +
右侧横向基础设施栏。第一章结束时它是唯一总结图，也是后续各章引用的那张图。

2. **1.2 重写**：换成“拆开看有什么”，六个部分（本体与关节／执行器／传感器／末端执行器／电源与通信／算力）；删掉 23/29 DoF 变体表、SDK 索引注释、URDF 结构段落；“不同专业看 G1”与 1.3 的“四张架构图”合并成末尾一次讲解。
3. **1.3 合并重写**：功能链成为唯一架构；各层详解、三个流、模块速查表、四问四答、SDK 代码片段、SystemLoopMapping 全部删除；“大脑／小脑”降为表里一列并明确写出是教学比喻；红杯子案例、频率、算力、横向基础设施、在线／离线保留。
4. **新增 canonical 图 SystemMap.astro**（六层 + 频率 + 上行反馈 + 横向基础设施侧栏），删除 SystemLoopMapping.astro 与 LowCmdLowStateSnippet.astro；G1CommandJourney 的层标注改为功能层名。
