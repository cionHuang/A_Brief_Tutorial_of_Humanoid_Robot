# 第一章重构审计（Phase 1）

对象：`chapters/01-system-overview/` 的四节，正文合计 **11,475 汉字**（1.1 1,761 / 1.2 2,514 / 1.3 3,912 / 1.4 3,288）。

审计要回答一个问题：**同一台机器人，被用几套分类方式重复介绍了几遍？**

---

## 1. 当前每节的真实职责

| 节 | 标题承诺 | 实际在讲 | 与承诺是否一致 |
| --- | --- | --- | --- |
| 1.1 | 具身智能是什么 | 定义（身体／闭环／交互进化）+ 物理 AI + 莫拉维克悖论 + 为什么用人形 | 略超：一节里出现 **4 个概念中心** |
| 1.2 | 定义、构造与 G1 | 人形定义 + 5 个术语（DoF／执行器／传感器／浮动基座／末端执行器）+ G1 变体表 + 不同专业视角 | 超载：G1 变体、URDF、SDK 索引注释进入主线 |
| 1.3 | 系统架构：分层与接口 | 五层「按部位」架构 + 各层详解 + 三个流 + G1 层名 | 与 1.4 重复介绍同一台机器 |
| 1.4 | 从一句话到电机：整机总图 | 六层「按功能」功能链 + 频率 + 算力 + 两个闭环 + 红杯子案例 + 横向基础设施 | 与 1.3 重复介绍同一台机器 |

**核心病灶**：1.3 与 1.4 各自完整地讲了一遍"这台机器分成哪些层、信息怎么走"，
只是分类口径不同（1.3 按部位命名，1.4 按功能命名）。读者读完的感受是
"刚学会一套架构，又来一套新的"。
