### 2.3 模板化语言与叙事多样性

- 「一句话听懂」318 处，33 节都有「先看一个现场问题」——统一人格已经建立，但**每节都走同一套模板**：现场问题 → 术语 → 一句话听懂 → 上下游 → G1 落地。
- 「本质上」2 处、「换句话说」2 处、「简单来说」0 处——此前清理过一轮，措辞层面已不严重。
- 真正的问题是**结构层面**的重复感：数学/模型类、物理子系统类、开发工具类、研究范式类节都用同一个骨架，读者到第 3 章以后会产生“又是这一套”的疲劳。
- 目标第三、九、十六、十七条要求：按节类型选择叙事（运行时模块 / 数学模型 / 物理子系统 / 开发工具 / 训练生命周期 / 研究范式），并允许不同类型的开场。

### 1.1 我们到底在研究什么：具身智能与人形机器人

- **希望新人带走**：具身智能 = 一个身体 + 自己转的感知—行动环；为什么用人形做教具。

- **过强结论**：无明显问题。**问题链**：结尾“四个专业四张图”自然引出 1.3。

### 1.3 从任务到电机：一台现代人形机器人如何运行

- **希望新人带走**：唯一总图（六层 + 两条链 + 横向基础设施 + 多速率 + 在线/离线）。
